Mini-Dealership — Son Rapor (LaTeX / Overleaf)

Bu klasör Overleaf'e olduğu gibi yüklenebilir.

1) Overleaf: New Project -> Upload Project -> bu zip dosyasını seçin.
2) Menu -> Compiler -> XeLaTeX seçin (pdfLaTeX değil).
3) Ana dosya: son-rapor.tex
4) Derleyin.

Notlar:
- figures/ altındaki panel görüntüleri ve EER/şema görselleri hazırdır.
- WhatsApp ekran görüntünüzü figures/whatsapp.png olarak eklerseniz
  Şekil 9 otomatik olarak o görseli kullanır. Yoksa yer tutucu kutu görünür.
- Örnek derlenmiş PDF: son-rapor.pdf
- Yerelde derlemek için: tectonic -X compile son-rapor.tex

İçerik: 8 bölüm (problem, gereksinimler, EER, mantıksal tasarım, uyarlama,
uygulama, sonuç, kaynaklar), test tablosu ve ölçümler.
